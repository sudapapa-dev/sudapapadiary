# Sudapapa Diary

> 바탕화면 위에 펼치는 **나만의 다이어리** — Windows 데스크톱 위젯 + 다이어리 앱

캘린더 5종 · 메모 · 즐겨찾기 · 암호 복사 · 알람/타이머 시계까지 **9종의 위젯**을 데스크톱 위에 자유롭게 띄우고, Google · Microsoft · Naver · Kakao 캘린더와 양방향 동기화합니다.

📖 **[전체 사용자 가이드 →](https://sudapapa-diary-api.engineercjy627.workers.dev/guide/)** &nbsp;|&nbsp; 🏠 **[제품 소개 페이지 →](https://sudapapa-diary-api.engineercjy627.workers.dev/)**

---

## 핵심 기능

| 분류 | 내용 |
|------|------|
| **데스크톱 위젯 9종** | 미니/대형 월간·주간·통합 캘린더, 일정 목록, 메모(다중), 즐겨찾기, 암호 복사, 시계(알람·타이머) |
| **외부 캘린더 연동** | Google Calendar · Microsoft 365 · Naver CalDAV · Kakao — 다중 계정 + 양방향 동기화 |
| **빠른 일정 추가 (QuickAdd)** | 트레이 좌클릭 → 즉시 일정 등록. 자연어 시각 파싱 지원 |
| **알람·타이머** | 시계 위젯에서 통합 관리 + 절전 복귀 후 누락 알람 자동 보정 + 백그라운드 카운트다운 |
| **메모 (마크다운)** | 다중 인스턴스, 일정 `@`멘션, 자동 저장 |
| **암호 금고** | OS Keychain 기반 암호화 저장 + 위젯에서 빠른 복사 |
| **공휴일** | 다국가 공휴일 자동 동기화 |
| **다국어** | 한국어 외 15개 언어 (en · ja · zh-CN/TW/HK · de · fr · es · it · pt · ru · sv · no · tr · vi) |

자세한 위젯·설정·연동 가이드는 [사용자 매뉴얼](https://sudapapa-diary-api.engineercjy627.workers.dev/guide/)을 참고하세요.

## 설치

| 방법 | 설명 |
|------|------|
| **인스톨러 (.exe)** | 시작 메뉴 등록 + 자동 업데이트 채널 연결 — 대부분의 사용자에게 권장 |
| **Portable (.zip)** | 압축 해제 후 실행, USB 휴대 가능. 자동 업데이트 미지원 |

다운로드 및 SmartScreen 경고 해결 방법: [설치 가이드 →](https://sudapapa-diary-api.engineercjy627.workers.dev/guide/getting-started/installation/)
